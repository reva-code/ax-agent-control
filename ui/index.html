One agent per task. Each is a Claude Code session on its own copy of the repo, sized by role (coder / test writer 1 GiB · docs writer 768 MiB). Substrate starts agents only where they fit; the rest wait. Each agent shows its diff, gets a read-only AI review, then waits for yours, suspended to storage with no CPU or RAM. Approve it and it finishes (and pushes its branch if enabled). Results appear at the bottom of the page.

Utilization

Pause: freezes the agent where it is; it resumes on the same node Suspend: saves the agent's full memory to shared storage and frees the machine; you choose the node it resumes on
Snapshot storagesuspended agents use no compute; their complete state is saved here
Finishedsandbox deleted, slot freed for the next agent
